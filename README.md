# My SQL Journey

A structured collection of SQL and PL/SQL learning materials.  
Includes topic-wise scripts, solved practice sets, and handwritten theory notes.  
Created to help learners strengthen database concepts, improve query writing skills, and prepare for exams or interviews.

---

## 📂 Repository Contents
- **SQL Scripts**: Topic-wise examples and exercises  
- **PL/SQL Programs**: Procedures, functions, and triggers  
- **Practice Sets**: Solved problems for hands-on learning  
- **Handwritten Notes**: Theory notes for quick revision  

---

## 🎯 Purpose
This repository is designed as a learning path for:
- Students preparing for exams  
- Beginners building SQL/PLSQL skills  
- Developers revising database concepts  
- Interview preparation
